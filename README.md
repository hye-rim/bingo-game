# 숫자 빙고 🎱

1~25 로 내 빙고판을 만들고 번갈아 숫자를 불러 먼저 5줄을 만드는 숫자 빙고. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- 5x5 칸에 1~25 를 한 번씩 적은 내 판을 만든다: **🔀 섞기**(무작위) 또는 **✍️ 직접 채우기**(1부터 차례로 칸에 놓기, 방금 놓은 숫자는 다시 눌러 지울 수 있다)
- 번갈아 아직 안 나온 숫자 하나를 부른다. 부른 숫자는 **두 사람의 판에서 모두** 지워진다. 상대 판은 끝날 때까지 보이지 않는다
- 가로 5·세로 5·대각선 2, 모두 12줄 중 한 줄이 다 지워지면 1줄. **먼저 5줄**을 만들면 이긴다. 한 번 부른 숫자로 둘 다 5줄이 되면 부른 사람이 이긴다(무승부 없음)
- 컴퓨터 쉬움은 아무 숫자나 부르고, 어려움은 **60% 확률로만** 내 판에서 줄이 가장 빨리 완성될 칸의 숫자를 부르고 나머지는 아무 숫자나 부른다 (상대 판은 모르니 내 판만 본다). 늘 그렇게 부르는 최선의 요령(`best`)은 사람이 낼 수 있는 가장 좋은 수라서, 어려움을 그대로 두면 쉬움을 98%나 이겨 사람이 이기기 어려웠다. 지금은 어려움이 쉬움을 약 85% 이기고, 최선의 요령으로 두는 사람이 어려움을 약 80% 이긴다(어려움도 가끔은 이긴다). 비율은 시험으로 확인한다
- 컴퓨터를 이긴 횟수는 `bingoWins` (로비 표시용), 온라인 전적은 `bingoOnline`
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 판 만들기 60초(안 누른 쪽이 지고, 둘 다 안 누르면 방이 닫힘) · 숫자는 부를 때마다 30초(넘기면 시간패) · 기권 · 한 판 더(먼저 부르는 쪽이 바뀜) · 끊겨도 30초 안에 돌아오면 이어서. 서버가 같은 규칙(`public/logic.js`)으로 줄 수와 승패를 정하고, **상대 판은 게임이 끝나기 전에는 서버가 보내지 않는다**. 차례가 아니거나 규칙에 어긋난 입력, 1~25 가 한 번씩이 아닌 판은 무시한다. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- M 소리

규칙과 컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인 연결은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(규칙·컴퓨터), `test/server.test.js`(서버를 띄워 두 손님이 한 판을 끝까지 두는 흐름·상대 판 숨김·입력 검사·재접속 등).
